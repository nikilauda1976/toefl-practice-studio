# TOEFL Practice Studio

Page d'entraînement au TOEFL iBT 2026, une seule page HTML sans installation.

- Ouvrez `index.html` dans Safari ou Chrome, ou la page GitHub Pages du dépôt.
- Les exercices changent à chaque ouverture, les nouveaux et les plus difficiles passent en premier.
- L'onglet Envoyer à ma prof prépare un e-mail, un document Word et un enregistrement audio du speaking.
- La progression reste dans le navigateur de l'appareil utilisé.
- La correction automatique fonctionne dans la version Claude. Ici, le bouton Corriger copie le texte pour Claude.
